Load recommendations

Learn, then personalize: on a new exercise, Iron Six can give a conservative starting estimate using body weight, age, training level, exercise type, and equipment limits. The moment the user logs actual load + reps + RIR, those real performance data take priority. If a user does more than prescribed with reps left in reserve, the next-set and next-session suggestion rises; if they miss the rep range or hit failure, it falls.

How adaptation works

Equipment: exercise selection always respects the active profile’s available gear.

Load: actual performance overrides demographic estimates as soon as it exists.

Variation: each workout begins with Variant A. After roughly four successful exposures, Variant B can unlock; after roughly eight, Variant C can unlock. Variants alter angles/accessories while preserving the main movement pattern so progress stays measurable. Excessive random exercise swapping is intentionally avoided.

Time-aware workouts

15–20 min: highest-value strength patterns only.

30 min: primary strength work plus targeted unilateral/core work.

45 min: adds meaningful hypertrophy volume.

60+ min: full strength-and-size session. Short workouts are rebuilt around priorities instead of simply cutting off the end.

Landmine integration

Lower: landmine reverse lunge, squat, and hinge variations when they improve loading or joint comfort.

Shoulders / chest: half-kneeling or standing landmine press as a shoulder-friendly pressing accessory.

Back: landmine row / Meadows-row variations for heavy horizontal pulling.

Core: landmine rotations for controlled rotational strength. The landmine complements the main barbell lifts rather than replacing them automatically.
